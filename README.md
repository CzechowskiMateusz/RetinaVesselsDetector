# RetinaVesselsDetector

This project focuses on detecting blood vessels in retinal fundus images using image preprocessing and machine learning techniques. Implemented in Python, it features interactive image selection, enhancement, feature extraction, classification, and result visualization, all within a Jupyter Notebook environment.

## Features

- Interactive image selection via dropdown
- Preprocessing of retinal images (CLAHE, blurring, filtering)
- Feature extraction (e.g., Frangi filter, Hu moments)
- Classification using:
    - Random Forest
    - K-Nearest Neighbors (KNN)
- Visualization of classification results and metrics (accuracy, confusion matrix, etc.)
- Export of trained model via joblib
